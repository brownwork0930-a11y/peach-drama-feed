## 每日更新 / Daily posts

每天计划发布 **5 条**独立目录条目，时间为 **10:00、13:00、16:00、19:00、22:00（Asia/Taipei，GMT+8）**。上线时的首条验证帖计入当天的 5 条，不补发错过的时段。

每条内容使用来源中的真实剧名和已核验的同剧观看链接；已有公开 YouTube 预告时，附上对应 Short。作品不可用或审核未通过时，保留空缺，不用重复内容凑数。

- **18+** 说明作品来自成人目录，不代表仓库展示成人画面。仓库只发布非露骨的目录信息。

- 同一来源作品不重复发布。条目核验时间记录检查时间，不代替作品首发时间。
